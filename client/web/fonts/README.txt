CodexLinkSans.woff2 is a subset of Noto Sans CJK SC Regular.
CodexLinkMono.woff2 is Noto Sans Mono Regular in WOFF2 format.
Sources: installed noto-fonts-cjk and noto-fonts packages; upstream https://github.com/notofonts/noto-cjk and https://github.com/notofonts/noto-fonts
Both fonts are distributed under the SIL Open Font License 1.1; see OFL.txt.
CJK subset includes Latin, Greek/Cyrillic, punctuation, kana, CJK Unified Ideographs and available CJK extensions.
Font data retains upstream copyright/name metadata.

CodexLinkSymbols.woff2: NotoSansSymbols2-Regular.ttf from the system Noto font package, converted to WOFF2. SIL OFL 1.1; see OFL.txt. Provides symbol fallback without a Google Fonts request.

CodexLinkEmoji.woff2: Noto-COLRv1.ttf from https://github.com/googlefonts/noto-emoji/tree/main/fonts, converted to WOFF2 (1,996,860 bytes). SIL OFL 1.1; see OFL.txt. Locally bundled color emoji prevents repeated external Noto Color Emoji requests. Upstream copyright/name metadata is retained.
